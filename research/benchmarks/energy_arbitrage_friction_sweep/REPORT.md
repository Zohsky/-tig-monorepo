# T52 friction blend sweep

Дата: 2026-08-05. Платформа: Apple arm64, native Rust debug test build.

Проверено линейное смешивание legacy и corrected friction:

`friction(alpha) = legacy + alpha * (corrected - legacy)`.

Для каждого `alpha` использованы те же детерминированные nonce 0–4, что и в
`energy_arbitrage_paired`. Каждое решение повторно проверено полным challenge
evaluator; invalid solutions: 0 из 15.

## Решение

Для T52 выбран `alpha=0.25`: на этой выборке он улучшает mean quality на 307
относительно legacy и на 680 относительно corrected. T51 и T53 остаются на
`alpha=1.0`, поскольку исходный paired benchmark показал положительное среднее.

Выбор предварительный: разница мала, N=5 и native debug build не измеряет TIG
fuel. Перед leaderboard-релизом требуется 25–30 новых nonce в instrumented Linux
build с отдельными tuning и holdout наборами.
