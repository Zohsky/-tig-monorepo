# Paired benchmark: legacy `2κ` vs asymmetric friction

Дата: 2026-08-05. Платформа: Apple arm64, native Rust debug test build.

## Дизайн

- Одинаковые детерминированные seed/nonce для каждой пары.
- Legacy: `(charge_friction, discharge_friction) = (2κ, 2κ)`.
- Corrected: `(κ(1+η), κ(1+1/η))`.
- Все остальные исходники, hyperparameters и условия одинаковы.
- T49–T52: nonce 0–2; для спорного T52 добавлены nonce 3–4.
- T53: nonce 0 (одна пара занимает около 7.5 минуты в debug build).
- Quality и profit пересчитаны challenge evaluator, а не извлечены из solver.
- Изменённым считается действие с `|Δu| > 1e-6`.

T49–T50 являются negative controls: они используют отдельные track engines и
не должны реагировать на переключение helper.

## Runtime и fuel

Наблюдаемый debug wall-time пары не заменяет TIG fuel. Примеры:

- T49: около 0.17–0.21 с на вариант;
- T50: около 6.4–6.8 с;
- T51: около 49–56 с;
- T52: около 25–33 с;
- T53 nonce 0: legacy 225.8 с, corrected 227.5 с.

Официальный `fuel_consumed` не измерен: macOS-среда не содержит TIG Linux
dev-image, Docker и модифицированный LLVM fuel injector. Нативный символ fuel в
test harness неизменяем, поэтому показание `policy_spent=0` намеренно не
интерпретируется как расход fuel.

## Repair

Все 30 полученных решений успешно прошли полный challenge evaluator, то есть
invalid/final-feasibility failures = 0. Точное количество внутренних repair
invocations измерить постфактум нельзя: текущие движки не экспортируют такой
счётчик. Добавление счётчика в production изменит инструментированный fuel;
правильный способ — отдельная diagnostic build обеих версий и повторный paired
прогон в TIG dev-image.

## Вывод

1. Контроль T49/T50 побитово совпал — harness действительно изолирует формулу.
2. Формула сильно влияет на T51–T53: меняется 72–90% действий.
3. На этой выборке T51 и T53 выигрывают, T52 слегка проигрывает в среднем.
4. Поэтому глобально объявлять corrected formula победителем преждевременно.
5. Рациональное продолжение: оставить исправление как экспериментальную ветку,
   выполнить минимум 25–30 nonce на T51–T53 в release/instrumented build и отдельно
   переоптимизировать action-grid/threshold hyperparameters T52 под новую формулу.

Сырые решения находятся в `raw/`, повторно вычисленные метрики и расписания — в
`eval/`. Воспроизводимый harness расположен под `#[cfg(test)]` в `titan_v6` и
`energy_arbitrage` challenge tests, поэтому production build не меняется.
